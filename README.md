# BPRO – Personal Portfolio / Resume Template

## Overview

**BPRO** is a modern, clean, and fully responsive personal portfolio and resume template designed to showcase professional profiles, projects, skills, services, and contact information. It is suitable for developers, designers, freelancers, software engineers, photographers, content creators, instructors, and other professionals who want to establish a strong online presence.

Built with **HTML5**, **CSS3**, **JavaScript**, **Bootstrap 5**, **Sass**, and **PHP** (for the contact form), BPRO delivers a fast, responsive, and user-friendly experience across all modern devices and browsers.
